# Aegis Markets 项目使用说明书

## 项目简介与范围

Aegis Markets 是部署于 Solana devnet 的 Aave V3 风格借贷 MVP。它使用 Rust + Pinocchio，无 Anchor 运行时；支持管理员配置任意 SPL Token 市场，因此常见 token 与 xStocks 都可在拥有 devnet mint 和 Pyth feed 时接入。当前版本实现市场初始化/参数更新/暂停、用户仓位创建、供应、取回、借入和还款。

当前版本未经审计，只适合开发网演示。尚未实现跨资产统一健康度、清算、实际利率指数累计、eMode、隔离模式债务上限、闪电贷和 Token-2022 CPI；不能用于真实资产或生产环境。

## 架构与目录

- `program/src/lib.rs`：Pinocchio 链上程序、账户校验、Pyth 解析、SPL Token CPI。
- `app/`：Next.js App Router dapp 与显式 ABI 编码器。
- `docs/ABI.md`：指令 tag、二进制布局、账户顺序、PDA 和错误码。
- `program/keys/`：本地 program keypair（被 `.gitignore` 排除，绝不提交）。

## 环境和安装

需要 Rust、Solana CLI 4.x、`cargo-build-sbf`、Node 22+ 与 pnpm 11+。

```bash
cargo build-sbf
cargo test
cd app
pnpm install
cp .env.example .env.local
pnpm dev
```

浏览器访问 `http://localhost:3000`。钱包网络必须切到 devnet；默认 RPC 为 `https://api.devnet.solana.com`。

## 页面操作

连接 Phantom 或 Solflare devnet 钱包。首次点击“创建仓位 PDA”。供应/取回/借入/还款时填写 mint、用户 token account、由 reserve PDA 控制的 vault、对应 Pyth `PriceUpdateV2` 账户，以及 token 最小单位金额。提交后页面依次显示钱包确认、链上确认和交易签名摘要。

Admin 钱包连接后显示管理控制台，可初始化协议、按保守默认风控值创建市场，并暂停或恢复 reserve。创建前必须逐字符核对 mint、Pyth feed ID 和 decimals；参数编辑的完整二进制布局见 `docs/ABI.md`。

## Pyth 与资产接入

从 Pyth 官方 price-feed 列表选择 feed ID，并通过 Hermes/Receiver 生成或更新完全验证的 `PriceUpdateV2` 账户。链上程序校验官方 Receiver owner、完整验证等级、feed ID、更新时间、正价格和置信区间。xStocks 只有在发行方提供 devnet SPL mint 且 Pyth 有相应 feed 时才能作为真实测试市场；否则只能创建明确标注的 mock token，不能冒充真实 xStocks。

## 构建、测试与部署

```bash
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo build-sbf
solana config get
solana address
solana balance
solana program deploy target/deploy/aave_v3_solana.so --program-id program/keys/program-keypair.json --url devnet
```

部署前必须确认 RPC 是 devnet、钱包可读、SOL 足够，且源码 Program ID 与 program keypair 公钥一致。Program ID、交易和账户可用 Solana Explorer 的 `?cluster=devnet` 查询。

## 常见错误

- `Unauthorized`：连接的钱包不是配置 admin，或 position 不属于签名者。
- `InvalidOracle` / `StalePrice`：价格账户 owner/feed 不匹配、未完整验证或过期；先更新 Pyth price account。
- `PriceConfidence`：行情置信区间超过市场限制；等待市场稳定或由 admin 审慎调整。
- `HealthFactor`：取回或借入会使仓位低于阈值。
- `InsufficientLiquidity`：vault 余额或 borrow cap 不足。

## 安全注意事项

所有金额使用最小单位；禁止提交私钥、`.env.local` 或 `program/keys/*.json`。本项目未通过第三方审计，且当前清算入口被禁用。任何主网部署、真实 xStocks 使用或开放存款前，都必须完成跨资产会计、利息与清算实现、模糊测试、经济模型验证和独立安全审计。
